# 居民燃气费账单异议与用量复核系统

居民对某个账期的燃气费用有疑问时，可在线提交异议；客服调取抄表记录、安排现场复核，
确认估抄偏差后生成调整单，跨期补收 / 退款分别记入流水。原账单快照与原始抄表照片始终保留，
复核未完成或住户未确认结论前，申请不会自动关闭。

## 技术栈

- **后端**：NestJS + Prisma + SQLite（端口 3001）
- **前端**：React + Vite（端口 5173，代理 `/api` → 3001）
- **本地模拟接口**：模拟抄表机（现场复核回执）、模拟通知网关（发件箱）
- **测试**：Jest + supertest（独立 SQLite 测试库）

## 快速开始（一条命令）

```bash
npm start
```

首次运行会自动：安装依赖 → 初始化 SQLite（prisma generate + db push + seed）→ 同时启动前后端。

- 前端：http://localhost:5173
- 后端：http://localhost:3001/api

## 演示流程

1. 住户 `zhangsan` 登录 → 我的账单 → 打开 **2026-08**（实抄补回估抄欠款，账单暴涨）→ 提交异议
2. 客服 `agent01` 登录 → 异议工单 → 受理并预约上门时间
3. 客服在工单中 **调用模拟抄表接口** 获取现场回执（含现场照片）→ 更正 6、7 月估抄读数
   （1240→1252、1270→1296）→ 生成调整单
4. 系统跨期重算三个账期，补收 / 退款分别入账：

   | 账期 | 原用量 | 更正用量 | 差额 | 入账 |
   |---|---|---|---|---|
   | 2026-06 | 30 m³ | 42 m³ | +38.40 元 | 补收 |
   | 2026-07 | 30 m³ | 44 m³ | +44.80 元 | 补收 |
   | 2026-08 | 88 m³ | 62 m³ | −83.20 元 | 退款 |

5. 住户核对「原金额 + 调整原因 + 补退明细」→ 接受结论关闭，或 **仍有异议** 退回重新受理
6. 读数曲线标明估抄（空心橙点）/ 实抄（蓝点）/ 复核更正（绿点），被更正的原始估抄读数
   以灰点保留在图上；原账单与原始抄表照片均可回查

## 运行测试

```bash
npm test
```

20 个用例覆盖需求中的关键验证点：

- **跨期差额计算**（`test/calc.spec.ts`）：更正一条估抄影响相邻两期（一补一退）；
  连续更正两条影响三期且总量守恒；单调性 / 估抄限定 / 重复更正等校验
- **重复回执幂等**（`test/review-flow.e2e-spec.ts`）：同一回执再次提交 → 409，
  调整单与流水不重复；住户再异议重开后旧回执仍不可复用；新回执也不能二次更正同一读数
- **不自动关闭**：复核未完成不能结案；结论未确认前状态不会进入 CLOSED
- **数据隔离**（`test/authz.e2e-spec.ts`）：住户只能读自己的账单、读数曲线、抄表照片、
  异议与流水（越权一律 404），客服接口对住户角色 403，未登录 401

## 关键设计

- **账单快照**：`Bill` 保存期初/期末读数、用量、单价、金额，复核调整不改写原账单；
  更正读数另存新行（`supersedesId` 指向被更正的估抄），原始读数与照片保留
- **跨期差额**：期末读数同时是下期期初，更正一个估抄点会影响相邻账期。
  `src/adjustments/calc.ts` 为纯函数，对整表账单重算并产出每期差额
- **幂等**：抄表回执号 `receiptNo` 是调整单的唯一键，回执消费（`consumedByAdjustmentId`）
  与调整单创建在同一事务内完成；并发/重试由唯一约束兜底 → 重复回执不可能重复调整同一笔账
- **状态机**：`SUBMITTED → REVIEW_SCHEDULED → CONCLUSION_REACHED → CLOSED`；
  唯一关闭途径是住户显式接受结论，住户「仍有异议」则退回 `SUBMITTED` 重新受理
- **鉴权**：JWT + 角色守卫；所有住户数据查询按 `residentId` 过滤，越权返回 404（不泄露存在性）；
  照片接口同样校验归属
- **本地模拟接口**：`POST /api/mock/meter-reading/onsite`（抄表机，返回唯一回执号与现场照片）、
  通知网关写入 `Notification` 表并可在「通知发件箱」查看

## 目录结构

```

├── scripts/start.js      # 装依赖 → 迁移/种子 → 同启前后端
├── server/               # NestJS + Prisma + SQLite
│   ├── prisma/           # schema、种子（dev.db / test.db）
│   ├── src/
│   │   ├── adjustments/calc.ts   # 跨期差额纯函数
│   │   ├── disputes/             # 异议状态机 + 复核 + 幂等调整事务
│   │   ├── bills/  ledger/  files/  notifications/  auth/  common/
│   └── test/             # calc 单测 + 流程/隔离 e2e
└── client/               # React + Vite（读数曲线为纯 SVG 组件）
```
